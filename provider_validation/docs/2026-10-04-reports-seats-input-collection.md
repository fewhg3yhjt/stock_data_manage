# 东财研报列表与明确日期的龙虎榜席位

本批继续转换原成功归档，修改既有东财财务 Provider，不新增 Provider 或管理层。ASTOCK-008、ASTOCK-019 转为可手动执行的验证候选；当前43项候选、21项待转换、7项阻断、3项别名。自动调度、正式路由和生产写入均未启用。

## 实现和配置

`config/providers.yaml` 定义参数来源、既有类别频率、请求间隔和能力边界。研报使用单股票、起止日期、最多3页的配置；席位使用单股票和明确交易日，正交易日历门禁保留。类别频率及天/分钟策略沿用原配置，本批未改变调度范围。

`config/datasets/eastmoney_reports.yaml` 与 `dragon_tiger_seats.yaml` 定义标准字段、必填项及主键；`config/normalization/` 同名文件定义来源字段映射。实际候选入口执行这些配置，支持字段选择和映射修改；必填字段被排除时拒绝请求。金额、比例、预测指标等未经单位认证的标准数字列保持空值，原来源数值、精度字符串与数组完整留证。

原 `providers/eastmoney/financial.py` 增加 `fetch_report_list` 与 `fetch_dragon_tiger_seats`，原财务和其他既有方法语法树保持一致。现有工厂仅增加手动候选绑定；生产 Provider 配置保持一致。

研报保留原 reportapi URL、参数、Referer、Session、环境代理、30秒超时、实际成功探针的保守重试/退避和分页节奏。支持原 JSON/JSONP 解析；校验代码、日期窗口、来源总数、页码、字段、数值与跨页重复。首个空响应不认证为有效空数据；末尾空页按原短页结束规则处理。达到页上限时记录 `result_limited=true` 和来源总数，不能将截断列表当完整覆盖。发布日期只认证到日期，保留原发布时间文本；本批不下载 PDF。

席位保留原 SDK 两次确定接口请求及解析前响应字节，分别核对买入/卖出字段顺序、日期、代码、条数、业务状态和数值。原 SDK 的“序号”是类型排序后的行号，不认证为金额排名；以快照、代码、日期、方向和来源行号区分记录，不推断营业部永久身份。

原 `storage/raw.py` / `providers/transport.py` 增加显式、默认关闭的缓存忽略参数；仅 ASTOCK-008 的有效缓存匹配忽略随机时间戳 `_`。代码、窗口、分页、主机、方法、范围、代码版本及有效期仍必须匹配，实际请求和原缓存来源各自留证。离线回放仍严格匹配完整 URL；回放时钟仅作用于该函数，进程时钟保持。其他输入默认匹配规则保持。

## 原实现和实际来源范围

| 输入 | 归档实际范围 | 原实现对照 | 候选结果 |
|---|---|---|---|
| ASTOCK-008 | 600519，2026-09-01至2026-10-03 | 原请求1次，51个来源字段一致 | 2026-09-21研报1条 |
