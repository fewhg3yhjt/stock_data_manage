## 各来源数据域的边界

同一来源的证券目录、报价、历史K线、板块关系、资金流及财务事件分别声明能力，不能用一个接口的成功或失败代表整个来源。东财专项设计合并到本节后，不再另维护一套“当前已实现”清单；实现绑定以代码和 YAML 为准，验证范围以对应证据为准。

| 数据域 | 采集及使用限制 |
|---|---|
| 证券目录 | 股票、ETF、LOF、指数及板块范围分开声明；目录来源和行情来源可以不同 |
| 报价、批量快照和分时 | 分别声明参数、批量能力、来源时间及累计量额；收盘快照仅形成 provisional 日线 |
| 历史日线 | 核对资产、复权、日期窗口和分页，不用快照证明历史覆盖 |
| 行业、概念及成分 | 目录、指数行情、成分关系和即时资金流分别建模；同花顺来源不能归成东财接口 |
| 资金流 | 个股、行业、概念分别定义字段与单位，即时排行不能冒充历史逐日数据 |
| 财务、股东及龙虎榜 | 指标、完整报表、报告期、公告日期、席位明细分别定义合同，不复用行情的覆盖结论 |
| 分红实施 | 服务于前复权历史变化发现，不是日线主来源；只接入已实施事件，预披露方案保留原始证据，不伪造除权日 |

每项正式接入须有已有Provider实现、字段模板和映射、离线合同、真实小范围探针、语义及端到端验证。HTTP200、SDK函数存在或少量样本成功均不能代替生产资格。失败只作用于匹配能力，不自动禁用其他接口、不改写已发布记录。

东财旧设计中的网络失败、样本行数和“未实现”列表具有历史时点，不能直接复制为当前状态。当前待办集中到项目进度，动态路由资格读取现有元数据；旧抽样事实见 [2026-10-03历史能力矩阵](../../PROVIDER_CAPABILITY_MATRIX.md)，该矩阵不再作为当前能力入口。
